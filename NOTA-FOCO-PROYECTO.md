# Foco actual del proyecto

- La aplicación activa para desarrollo y mantenimiento es `admin-app` en Python.
- `electron-app` se considera legado y ya no debe tomarse en cuenta para nuevos cambios o análisis, salvo instrucción explícita.
- Cualquier corrección funcional relacionada con campañas, cartas, Firebase o distribución a gestores debe implementarse primero en `admin-app`.
